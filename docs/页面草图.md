# 页面结构草图

本文件用于确定布局与交互，不是最终视觉稿。昵称用“我”和“小伴”代指配置值；示例积分和内容仅用于说明。

## 视觉方向

暖白纸面、浅杏色按钮、低饱和鼠尾草绿辅助色，正文用深暖灰保证对比度。圆角适中，阴影轻。使用系统中文字体，正常字距。所有图标使用 SVG 并配文字，无 emoji、闪光特效或催促文案。

主页面围绕一张卡，避免铺满统计数字。桌面内容居中，手机单列。顶部放次级功能；底部 dock 始终只有两个卡位。

## 1. 首次进入

```text
                 我们的刮刮卡

          访问口令  [                 ]
                    [ 进入 ]

          验证通过后，首次设置：
          你的昵称  [                 ]
          助手昵称  [                 ]
                    [ 收好名字，开始 ]
```

后续直接进入首页。昵称可在设置中修改，历史卡片按身份关联，不受改名影响。认证失败保留输入区域，不展示业务数据。

## 2. 首页：待我刮

```text
我们的刮刮卡                 碎碎念 归档册 流水 设置

我有 80 分                         小伴有 35 分

                 我 · 第 3 张
                 小伴写给你的

       ┌───────────┐   ┌───────────┐
       │  密封纸层  │   │  已经刮开  │
       │   20 分   │   │  一首小诗  │
       └───────────┘   └───────────┘
       ┌───────────┐   ┌───────────┐
       │  密封纸层  │   │  密封纸层  │
       │   15 分   │   │   30 分   │
       └───────────┘   └───────────┘

                    已揭晓 1 / 4
                [ 给这张卡留句话 ]

          [ 待小伴刮 ]      [ 待我刮 · 当前 ]
```

已刮格展示简短摘要，点击打开完整内容。密封格的价格和状态对双方可见。已完成时显示完成摘要和归档入口；没有收到卡时显示“这里留给下一份惊喜”。

## 3. 刮开一个格子

```text
                   第 1 格
              这次需要 20 分
              你现在有 80 分

       开始后扣分，关掉页面也能回来查看。

          [ 再看看 ] [ 花 20 分，开始刮 ]
```

成功后出现可拖动刮层，底部始终有“直接揭晓”。刮开大部分后柔和淡出剩余刮层，露出完整文字和“写点感想”。不播放金光或庆祝音效。

余额不足：显示“还差 5 分，可以先看看其他格子”，提供关闭入口；不自动向对方索要积分。网络结果不确定时显示确认中，复用原请求恢复状态。

## 4. 首页：待小伴刮

复用首页卡片布局。主操作是“奖励小伴积分”“写下一张卡”。格子不可被人类点击刮开。

默认仍展示密封外观，通过“查看我写的内容”进入作者视图，避免把作者预览和刮卡混淆。作者视图不能改变格子的揭晓状态。

奖励弹窗包含分数、必填理由和“送出积分”；成功后更新余额。提交中禁用按钮，失败重试复用请求 ID。

## 5. 写卡

```text
写一张给小伴的卡

格数  [ 4 ]                    草稿 · 尚未发布

第 1 格     价格 [ 20 ] 分
内容  [ 写下一份惊喜……                     ]

第 2 格     价格 [ 15 ] 分
内容  [                                   ]

             [ 保存草稿 ] [ 预览密封效果 ]
                         [ 发布这张卡 ]
```

预览仅模拟卡片外观，不调用刮卡接口、不扣分。发布前提示“发布后价格和内容就固定了”；当前卡没刮完时仍可保存草稿，发布按钮旁解释原因。离开未保存内容时提醒，第一版不将草稿缓存到浏览器。

## 6. 碎碎念本子

```text
碎碎念            卡片 [ 全部 ]   留言者 [ 全部 ]

             ┌─────────────────────────┐
             │ 小伴 · 我第 3 张 / 第 1 格 │
             │ 2026-09-27  15:20        │
             │                         │
             │ 想知道你会先挑哪一格。    │
             │                         │
             └─────────────────────────┘

             [ 上一页 ]  3 / 8 [ 下一页 ]
                    跳到 [ 3 ] 页
                    [ 写一条碎碎念 ]
```

写留言时选择卡片，可选格子；从卡片进入则预填关联。发送前提示“写下后会留在本子里”，支持预览。空筛选结果显示“这里还没有留言”。纸张效果只作装饰，不妨碍长文滚动和阅读。

## 7. 流水与归档

流水：时间倒序，顶部可切换双方。每行显示对象、`+20` 或 `−15`、理由、时间；刮卡行可打开对应已揭晓格子。余额放顶部，页面不做财务仪表盘。

归档：两方卡片混合按完成时间倒序，可按归属者筛选。每张摘要显示“谁的第几张”、作者、格数、完成时间。打开后看全部结果和对应留言，提供“再留一句”。

## 页面实现检查

- 手机宽度下无横向溢出，dock 不遮挡正文或按钮。
- 所有图标有文字或可访问名称，状态不只依赖颜色。
- 刮卡、翻页均可键盘操作，减少动画偏好下取消拖长的过渡。
- 加载、空白、积分不足、网络失败、认证失效和已被另一个页面刮开都有明确提示。
- 公共卡片摘要不携带密封内容；作者预览和结果读取分别验证权限。
